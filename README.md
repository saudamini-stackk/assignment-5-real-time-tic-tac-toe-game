# Real-Time Tic-Tac-Toe

A real-time multiplayer Tic-Tac-Toe game built using Node.js, Express, Socket.io, and MongoDB.

## Features

- Real-time 2-player gameplay
- X and O player assignment
- Win and draw detection
- MongoDB game history
- Automatic game reset
- Responsive UI

## Technologies

Node.js, Express, Socket.io, MongoDB, HTML, CSS, JavaScript
